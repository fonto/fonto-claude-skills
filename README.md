# README

A repository to store useful Claude skills:
* doc-sync is a set of skills to manage the documentation an existing codebase from a functional and technical perspective starting from the code (or by ingesting existing project docs), with the mechanisms to have a human assessments
* meeting-transcript-synthesizer turns a meeting transcript into a compte rendu (decisions, actions, risks, open questions) without inventing owners, deadlines or decisions the transcript does not support
